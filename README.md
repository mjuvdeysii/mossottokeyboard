# Mosto键盘 · Mosto Keyboard（iOS）

![Mosto](docs/images/mosto_sheet.png)

以小鹤双拼为主（两键一字、小写字母输入）、兼容全拼的 iOS 第三方键盘，核心是 **按触点位置的自动纠错**：点偏到相邻键时，结合手指落点概率与词频，把首选纠正为最可能想打的词。

## 功能

| 项目 | 说明 |
|---|---|
| 自动纠错 | 高斯触点模型 + 词库联合解码；首选带下划线表示已纠错，第二候选为原文；空格上屏了纠错结果后立刻按删除，会撤回这次纠错，恢复成按下的字母（同 Gboard） |
| 个人习惯 | 记录选过的词：词库里有的词在原词频上加分（选过的多字词下次排第一；单字加分有上限，选一次“得”不会把别处的“的”挤掉），分几次选完的句子记住各段怎么连；学习手指落点：整体偏移之外，每个键各自学习（拇指够边缘键、上排键的落点不同），学到的偏移只移动键的边缘、不改键的中心。基准（拇指偏离键心 0.22 键宽、上排偏低）：用 1000 个词后，未打过的词首选命中 74.6% → 80.4%。基准：句子选过一次后再打 97.6% 一次出对，没打过的句子不受影响 |
| 候选栏 | 只显示放得下的候选，不横向滚动；⌄ 展开全部候选（竖向） |
| 布局 | 按 Gboard iOS 实测尺寸（402 pt 屏宽）：工具栏 64、行距 53、键距 5.5×11；字母键不加数字角标 |
| 质感 | iOS 26 液态玻璃：键盘背景透明交给系统玻璃，圆角键帽 |
| 外观 | 自动（跟随系统浅色 / 深色，以及要求深色键盘的输入框，如聚焦搜索）、日光（系统键盘原样）、夜灯（深夜蓝，Mosto 在候选栏左边亮起金光） |
| 纯净 | 不做联想、不做滑行输入：只出当前按键的候选，最后一个候选始终是输入的字母原文 |
| 输入方案 | 小鹤双拼与全拼（含简拼、半截音节），设置里切换；两种方案都按触点自动纠错 |
| 词库与语言模型 | 雾凇拼音 rime-ice 的基础、扩展与腾讯词库共 187 万条；加上 Rime 八股文语言模型（[rime-octagram-data](https://github.com/lotem/rime-octagram-data)，LGPL-3.0），按前后文判断哪些词常连在一起（收货地址、再便宜、打疫苗），句首的词也参考输入框里光标前的字。基准（305 句日常短句，其中 180 句只用于检验、不参与调参）：键位全对时整句首选命中 小鹤 85.9%、全拼 86.2%（不用语言模型时 79%）；带触点误差 σ=0.22 时整句命中 81–84%；九宫格全拼整句 66%、小鹤前三 59% |
| 九宫格 | 中文键盘可选九宫格（1 分词、2 ABC … 9 WXYZ；左列 ，。？——打字时换成拼音选择列，点一下即定下对应几个键；右列删除、重输、换行），小鹤双拼与全拼都能用；每个键代表它上面的几个字母，由词库判断。基准（键位全对时首选命中）：全拼 词 66%、句 67%；小鹤双拼 词 49%、句 40%（双拼在九宫格上一键对应的音节多，歧义大） |
| 英文 | 英文模式按触点自动纠错并给出候选（3.9 万词）：错位、漏字母、多按一键、相邻两字母颠倒都能纠（teh → the、thnaks → thanks），dont → don't、im → I'm；空格或标点时替换，紧接着按删除可撤回。基准（σ=0.22 触点噪声）：照打原样 83.5% → 纠错后 99.1%，正确拼写的词 99.9% 不被改动 |
| 中英混输 | 中文模式下直接打完整的英文词：ok → OK、ios → iOS、iphone → iPhone、github → GitHub（不做前缀补全）；按词频和中文读法比较排序，de、he、me 等仍然先出中文。英文词表来自 [wordfreq](https://github.com/rspeer/wordfreq)（CC BY-SA 4.0），约 3.9 万词 |
| 输入框中显示 | 打字时把按下的字母写进输入框（九宫格写拼音），带下划线，选了候选才替换成汉字，同系统键盘；候选栏只放候选 |
| 表情 | 😊 打开表情页：常用 + 笑脸与人物、动物与自然、食物与饮料、活动、旅行与地点、物品、符号、旗帜，上下滑动，底栏一点跳到分类；只列出当前 iOS 能显示的表情；按住 😊 打开键盘设置。列表来自 [Emojibase](https://github.com/milesj/emojibase)（MIT） |
| 速度 | 字母键和九宫格键按下即上屏（不等手指抬起）；解码在后台线程，主线程只负责画键和往输入框写字母，候选随后出现；提交（空格、点候选）时只等正在进行的那一次解码。词库与英文词表都是内存映射的只读文件，键盘启动时不解析、不建树（英文字典树原先每次启动要现建约 14 MB）；查词通过文件尾部的“次音节表”定位，不在大表上做二分。全键盘每键解码 < 1 ms，九宫格全拼长句约 30 ms（均在后台） |
| Mosto | 键盘里的薰衣草紫小魔王（谐音“魔头”，OTTOSSOM 中 Moss 与 Otto 共同的另一面）：日光与夜灯下都待在候选栏左边，只有光线随键盘变（夜灯下尾巴尖亮起灯珠的金光）；打字时让位给候选，停下后缓缓淡入；点它打开设置；设定见 [docs/MOSTO.md](docs/MOSTO.md) |
| 符号 | 中/英两套 123、#+= 页面，与 Gboard 同排布，每页 ≤10 键/行，全部可见 |
| 数字 | `123` 打开完整的数字符号页（数字一行 + 常用符号，#+= 进入更多符号），符号好打；只填数字的输入框（电话、验证码、金额）自动换成九宫格数字键盘 |
| 无障碍 | 每个键都有 VoiceOver 读音（删除、空格、上档、中英切换等）；按键音分字母、删除、功能键三种，与系统键盘一致；震动和按键音可分别开关，按下瞬间发出 |
| 手感 | 自绘按键、整块区域统一处理触摸、多指连按不丢字也不乱序（字母、空格、回车都按按下的先后输出；按着 123 / 中英切换时另一指打的字照样输出）、按住空格左右拖动移光标（其余键帽变空白，拖得快移得多，按字符移动、表情不拆开）、删除长按加速；键盘各层都带 2% 的底色而不是全透明（键盘扩展里 iOS 不派发落在全透明处的触摸，按键之间的缝和顶行上方的快速点按会被吞掉） |
| 隐私 | 不联网；词库和学习数据只存在本机 |

## 键位

- 空格：上屏首选　回车：上屏字母原文　删除：逐键回退
- 底行：`123` · 😊 表情（按住打开设置）· `中/英` · 空格 · `，`（长按 `。`）· ↵
- 字母键不设长按；数字与符号在 `123` / `#+=` 页
- 表情：常用 + 八个 iOS 分类，上下滑动，底栏跳转分类；只列出当前 iOS 能显示的表情（Emojibase，MIT）
- 设置：输入方案、中文键盘（全键盘 / 九宫格）、中英混输、按触点纠错、按键震动、按键音、外观、清空学习数据；纠错只有一档（标准），不设强度选项

## 隐私

键盘不联网，不含任何统计、广告或崩溃上报代码。打字内容、学过的词和触点习惯只保存在设备上的键盘扩展里。“允许完全访问”只用于震动和按键音。
