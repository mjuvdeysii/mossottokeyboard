三步启用 Mosto键盘

  1. 打开 iPhone 的 设置 › 通用 › 键盘 › 键盘；
  2. 轻点 添加新键盘，在列表中选中 Mosto键盘；
  3. 在任意输入框长按地球键切换至 Mosto键盘即可使用（不开启“允许完全访问”也可正常完成全部输入与纠错）。

常见问答

不开启“允许完全访问”也能使用吗？

可以。全拼、九宫格、可选双拼、触点纠错、词库联想与表情/颜文字面板均 100% 本地运行，无需“允许完全访问”。该系统开关仅用于开启按键震动与系统声效。

如何在全拼、九宫格与可选双拼之间切换？

在 Mosto键盘中轻点顶栏右侧齿轮图标，或长按底栏 Mosto 图标打开控制台，即可直接切换全拼 / 双拼、九宫格 / 全键盘以及日光 / 夜灯外观。

如何清除我学过的词和触点习惯？

在键盘内打开控制台 › 学习，轻点“清空已学习的词语与触点习惯”即可立即清空；卸载应用后所有本地记录也会随系统容器彻底删除。

键盘内为什么不支持联网云同步？

我们希望键盘扩展成为绝对可信的纯离线输入工具：不发起网络请求、不读写剪贴板、不采集任何个人输入习惯，彻底消除隐忧。
