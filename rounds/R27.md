# R27 · 新用户前 3 分钟引导优化与简洁模式原生液态玻璃统一

## 背景与真机证据（Build 317）

- **前 3 分钟上手流失风险**：App 首次打开固定进入「上手」页，未添加键盘的新用户需要自行切到「启用」页。
- **简洁模式 2×2 宿主矩阵实测（`IMG_9226`–`IMG_9229`）**：
  - `IMG_9227.png`（Spotlight 深色 + 简洁夜光）观感无缝；
  - `IMG_9229.png`（微信浅色 + 简洁日光）在键盘与液态玻璃顶底缘之间仍有细微浅灰色阶横线；
  - `IMG_9228.png`（微信浅色 + 简洁夜光）与 `IMG_9226.png`（Spotlight 深色 + 简洁日光）因简洁模式使用不透明矩形 `root.backgroundColor`，在 iOS 26 圆角液态玻璃与底部地球栏之间出现明显矩形色块断层。
- **关键事实**：Mosto 模式全程使用 `Theme.touchable`（2% 透明）在微信内已验证零重影，说明微信重影已由 `heightConstraint` + `clipsToBounds = true` 根治。

## 改动清单

1. **R27.1a（`415c951` · `App/MossOttoKeyboardApp.swift:69`）**：首次启动检测 `KeyboardStatus.isAdded()`，未添加键盘时默认直达「启用」页，已添加后默认进「上手」页。
2. **R27.1b（`508942f` · `App/EnableScreen.swift:69`）**：以肯定句补充离线与默认权限说明（`照下面三步添加，大约半分钟；纯离线本地运行，保持默认权限即可使用。`）。
3. **CI 门禁前置（`7a299bf` · `.github/workflows/ios.yml`）**：将 `Python scripts syntax gate`、`No-sync-tap assertion` 与 `Offline assertion` 前置到快照渲染之前（2 分钟内快速失败）。
4. **R27.2（`Keyboard/KeyboardViewController.swift:532,550`）**：统一简洁模式与 Mosto 模式使用 `root.backgroundColor = Theme.touchable` 与 `glass = sysDark ? .dark : .light`，彻底消除 `IMG_9226`/`IMG_9228`/`IMG_9229` 的液态玻璃矩形色块断层，同时保证候选栏与双胶囊永远与宿主玻璃高对比度。

## 风险与验收要点

- **可逆性**：R27.2 仅涉及 2 行代码，若真机微信收起/弹出动画出现残影，1 行即可恢复不透明底色。
- **真机验收重点**：在微信（浅/深）与 Spotlight 中分别切换简洁模式 `日光`/`夜光` 与 Mosto 模式 `日光`/`夜灯`，验证零色块断层、零重影、候选字全场景高对比度清晰可读。
